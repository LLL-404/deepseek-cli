## 给 M1 的设计输入（重要度排序）

1. **F-1 落地判定必须基于文本变化**：`landed = count>0 && 文本非空 && !(count<=countBefore && text===lastBefore)`。
   count 无论增减都不可作落地必要条件（虚拟列表双向回收，第 2/3/4 轮三次实锤）。
2. **F-2 提交验证成立**：输入框清空 = 站点接受提交（第 5 轮 0 次补提交，10/10 干净）。
   语义进 M1：提交后输入框未清空 → 补回车（≤3 次）；始终不清空 → 明确报"提交失败"。
3. **F-3 无渲染黑洞（偶发）**：提交被接受但回合 300s 不挂载（50 分之 2）。
   M1 对策：落地等待期内若长时间（如 60s）无任何 DOM 变化 → 刷新会话页重取一次；
   到 max-wait 仍无回合 → 报错带证据（URL、count、think、popups），**不得**当作空答案返回。
   gate.ts 已加"落地失败现场取证"，M1 的 judge/编排层接手。
4. **F-4 locale 钉死 zh-CN** + 开关标签中英双语匹配（`深度思考/DeepThink`、`智能搜索/Search`），
   aria-pressed 祖先定位（xpath `ancestor::*[@aria-pressed][1]`）验证可用。
5. **F-5 KaTeX 数学伪影**：含公式的答案 innerText 有底数指数重复文本（第 5 轮 Q7：`a2+b2=c2\na\n2\n+b\n2\n=c\n2`）。
   与现版同级的已知取舍，文档标注即可。
6. **F-6 凭据模型验证**：持久 profile 登录一次跨进程重启有效；`down` 删目录即回到未登录。
