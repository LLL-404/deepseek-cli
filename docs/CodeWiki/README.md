# dskts Code Wiki

> 面向没读过源码的读者：用这套文档建立 `dskts` 的完整心智模型——它是什么、怎么跑、由哪些模块组成、关键函数各自负责什么、改哪里会牵动哪里。

## 这是什么

`dskts` 是 DeepSeek 网页版的命令行工具：在终端里提问，答案打到 stdout、过程日志打到 stderr，可以进管道、可以被脚本和其他 Agent 直接调。实现是 TypeScript + Playwright，由「CLI + 常驻 keeper」两个进程协作完成。

## 阅读约定

- **术语**：统一用词与释义见 [02-架构与时序](./02-架构与时序.md) 的「术语速查」。
- **定位方式**：正文以「文件 + 符号名」定位，行号只作辅助——行号会随代码改动漂移。
- **单一事实源**：凡在 `dskts/src/constants.ts` 里定义的常量（选择器、判定参数、端口等），正文一律不复述其数值，只给符号名与出处；对外可见的默认值、磁盘路径与实测性能数字会直接写出。
- **「未实测」标注**：凡未经实际运行验证的陈述都会显式标注。
- **历史存档**：本 Wiki 之外的 `output/`、`docs/` 内容（迁移规划件、外部评审原文、技术笔记）是历史记录，不代表当前状态。
