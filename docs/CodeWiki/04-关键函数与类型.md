# 04 · 关键函数与类型

> 一句话摘要：各模块导出符号的签名、职责、关键行为与调用方。

阅读提示：签名只写要点，省略不重要的类型细节；完整签名以源码为准。行内提到的常量取值一律不在此复述，见 [constants.ts](file:///d:/G/github/实用工具/DeepSeek命令行/dskts/src/constants.ts)。

## keeper 生命周期

来源：[keeper.ts](file:///d:/G/github/实用工具/DeepSeek命令行/dskts/src/keeper.ts)

| 符号 | 签名要点 | 职责与关键行为 |
|---|---|---|
| `ensureContext` | `() => Promise<Page>` | 复用活着的上下文；否则以 `launchPersistentContext` 起有头浏览器（钉死中文 locale、放宽启动超时以覆盖首次冷缓存），并在 context 关闭时清空句柄 |
| `opUp` | `() => Promise<{url}>` | 导航到 chat 页；未登录时等输入框出现（长超时，给人工登录留时间） |
| `opStatus` | `() => Promise<{pid, browser, url, loggedIn}>` | 状态快照 |
| `opCheckLogin` | `() => Promise<{loggedIn, url}>` | 导航 + 短暂等待 + 判断是否登录 |
| `opAsk` | `(params, emit?) => Promise<AskResult>` | 校验 `question` 必填；把 `maxWaitMs` **收口**到 `[5s, 上限]`（不信任帧参数，防畸形值把忙碌位拖死）；转交 `askFlow` |
| `opDown` | `() => Promise<{profileDeleted}>` | 关浏览器、清锁、删 profile 目录（重试若干次）；该帧的响应发出后 keeper 进程即退出 |
| `opChats` | `(params) => Promise<{rows}>` | 读侧栏锚点，为每条标注归属（`ownerOf`） |
| `opRm` | `(params) => Promise<RmResult>` | 转交 `rmConversation`，带 `yes` / `any` / `mark` |
| `opProbe` | `(params) => Promise<ProbeReport>` | 读数健康度诊断 |
| `opDiag` | `() => Promise<unknown>` | 在输入框中心取 `elementFromPoint`，排查浮层遮挡 |
| `handlers` | `Record<string, Handler>` | 命令名 → 处理函数（`ping` / `status` / `up` / `checkLogin` / `ask` / `chats` / `rm` / `probe` / `diag` / `down`） |
| `refuse` | `(socket, error) => void` | 坏帧或未授权帧的统一处置：先回一帧说明，再断这条连接，**绝不杀进程** |

`server` 的连接回调按固定顺序把关，顺序本身就是契约：

1. 解码失败（超长帧 / 非法 JSON）→ `refuse`
2. 形状校验：帧体不是 `{op: string, ...}` → `refuse`
3. token 校验：不符 → `refuse`
4. `busy` 检查：忙 → 回错误帧（`code 2`），**不断连**
5. 取处理函数：用 `Object.hasOwn` 防原型链
6. 执行并以帧回结果；`down` 成功后再退出进程

## 判定：createJudge

来源：[judge.ts](file:///d:/G/github/实用工具/DeepSeek命令行/dskts/src/judge.ts)

| 符号 | 签名要点 | 职责与关键行为 |
|---|---|---|
| `createJudge` | `(countBefore, lastBefore, config) => Judge` | 返回只有 `tick(reading)` 的状态机；终态后幂等返回同一判定 |

`tick` 一次调用的内部逻辑（三条判据彼此独立）：

| 判据 | 规则 |
|---|---|
| **落地认法** | 容器条数为 0、文本为空、或「条数未增且文本仍等于提交前那条」→ 尚未落地；否则记为已落地。**条数无论增减都不能当必要条件**（虚拟列表会双向回收） |
| **完成（双信号）** | 已落地、文本非空、与上一拍相同、且已等过最短时间 → 稳定计数 +1；稳定计数达标**且当前不 busy** → `done` |
| **抖动容忍** | 单拍读数失败按空采样跳过；连续失败达上限才收摊（有字按 `truncated`，无字按 `noRender`） |
| **上限收摊** | 等待总时长达到 `maxWaitMs` 时收摊：见过回合且有文本 → `truncated`，否则 `noRender` |
